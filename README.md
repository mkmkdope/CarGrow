# CarGrow Installation and Setup Guide
CarGrow is an Ethereum decentralized application (dApp) for milestone-based logistics escrow. 
This guide explains how to install the required software, deploy the `CarGrow` smart contract to Ganache, connect MetaMask, and run the web interface locally.

## 1. Required Software
Install the following before setting up the project:

1. **Node.js (LTS version)**  
   Download: <https://nodejs.org/>

   Node.js includes `npm`, which installs the project dependencies and runs the project commands.

2. **Ganache**  
   Download: <https://archive.trufflesuite.com/ganache/>

   Ganache provides a local Ethereum blockchain and test accounts containing test Ether.

3. **MetaMask browser extension**  
   Download: <https://metamask.io/download/>

   MetaMask connects the browser to Ganache and signs CarGrow transactions.

4. **A modern web browser**  
   Chrome, Edge, Brave, or Firefox may be used. Two separate metamask wallet profiles under single account are recommended when demonstrating the Shipper and Carrier simultaneously.

5. **A code editor**  
   Visual Studio Code is recommended.

## 2. Main Project Files
`contracts/CarGrow.sol` | CarGrow Solidity smart contract and business rules 
`scripts/deploy.js` | Deploys the CarGrow contract to the selected blockchain network 
`hardhat.config.js` | Solidity compiler and Ganache RPC configuration 
`js/app.js` | MetaMask connection, contract calls, data loading, and interface behaviour 
`index.html` | Main CarGrow user interface 
`css/styles.css` | Main layout and visual styling 
`css/forms.css` | Form, input, validation, and dialog styling 
`package.json` | Project dependencies and npm commands 
`artifacts/` | Generated contract ABI and bytecode after compilation 
`cache/` | Generated Hardhat compiler cache 

The `artifacts/` and `cache/` folders are generated automatically by Hardhat. They do not need to be downloaded separately and may be regenerated by running `npm run compile`.

## 3. Obtain and Open the Project
Place the complete CarGrow project in a local folder. Open the Visual Studio Code terminal inside that folder.

Example:

//powershell
cd "C:\Users\USER\BD"


Confirm that Node.js and npm are available:

//powershell
node --version
npm --version

Both commands should display version numbers. Restart the terminal after installing Node.js if either command is not recognised.

## //Installation Summary// 
For a new computer or a new copy of the project:

//powershell
npm install
npm run compile
npm run deploy:ganache


Then:
1. Copy the deployed contract address into `CONTRACT_ADDRESS` in `js/app.js`.
2. Configure MetaMask with the Chain ID shown by Ganache.
3. Import separate Ganache accounts for the Shipper and Carrier.
4. Start the interface:

   //powershell
   npm run serve
   

5. Open `http://127.0.0.1:5500`.

## Detailed Installation & SetUp Guide
## 4. Install Project Dependencies

From the project folder, run:

//powershell
npm install

This installs the packages declared in `package.json`, including:
- Hardhat
- Hardhat Toolbox
- `http-server`

The generated `node_modules/` folder should not be copied into a submission or committed to Git because it can be recreated using `npm install`.
** If the complete node_modules folder is copied, npm install might not be needed immediately. Copying or committing node_modules is strongly discouraged due it contains thousands of files and can be very large.

## 5. Create and Start the Ganache Blockchain
1. Open Ganache.
2. Create or open an Ethereum workspace.
3. Confirm that the RPC server is:

   http://127.0.0.1:7545

4. Keep Ganache running while compiling, deploying, and using CarGrow.
5. Record the following values shown by Ganache:

   - RPC server URL
   - Chain ID
   - Network ID
   - Account addresses
   - Private keys for test accounts

The project currently uses this network configuration in `hardhat.config.js`:

networks: {
  ganache: {
    url: "http://127.0.0.1:7545"
  }
}


If Ganache uses a different port, update the URL in `hardhat.config.js` before deployment.

Ganache accounts and private keys are for local testing only.

## 6. Add Ganache to MetaMask
In MetaMask, add a custom network using the values from the running Ganache workspace:

Network name | Ganache Local 
RPC URL | `http://127.0.0.1:7545` 
Chain ID | Use the Chain ID displayed by Ganache (Usually is 1337)
Currency symbol | ETH 

The MetaMask Chain ID must match the active Ganache workspace. Do not assume it is always `1337`, Use the value displayed by Ganache.

## 7. Import Ganache Test Accounts into MetaMask
CarGrow requires separate wallets to demonstrate its two roles:

- Account 1: Shipper
- Account 2: Carrier

For each account:
1. In Ganache, select the key icon beside the account.
2. Copy its private key.
3. In MetaMask, select **Import account**.
4. Paste the Ganache private key and complete the import.
5. Select the **Ganache Local** network.

A wallet can register only once as one role in a particular CarGrow deployment. Use two different Ganache addresses for the Shipper and Carrier.

For simultaneous testing, use two separate metamask wallet profiles under single account:

- Profile A with the Shipper account selected in MetaMask.
- Profile B with the Carrier account selected in MetaMask.

Using different Google accounts is optional. 

## 8. Compile the Smart Contract
With Ganache running, execute:

//powershell
npm run compile

Successful compilation generates the `artifacts/` and `cache/` folders. Compilation checks the Solidity syntax but does not deploy the contract.

## 9. Deploy CarGrow to Ganache
Run:

//powershell
npm run deploy:ganache


The terminal should display output similar to:

CarGrow deployed to: 0x1234...ABCD

Copy the complete deployed contract address.
Every deployment creates a new contract address and a new empty application state. Users, agreements, milestones, history, and reputation from an older deployment do not automatically move to the new contract.

## 10. Update the Frontend Contract Address
Open `js/app.js` and locate the constant near the top of the file:

```javascript
const CONTRACT_ADDRESS = "0x...";
```
Replace its value with the address printed by the latest deployment:
```javascript
const CONTRACT_ADDRESS = "PASTE_THE_NEW_CONTRACT_ADDRESS_HERE";
```

Save the file. The address must belong to the same Ganache workspace and network selected in MetaMask.
Repeat the deployment and address-update steps whenever `contracts/CarGrow.sol` is changed. Otherwise, the browser will continue communicating with the previously deployed contract.

## 11. Start the CarGrow Web Interface
Run:

//powershell
npm run serve


Open this address in the browser:

http://127.0.0.1:5500


Keep the terminal open while using the website. Stop the local server by selecting its terminal and pressing `Ctrl+C`.

Do not open `index.html` directly using a `file:///` address. Running the supplied local server avoids browser restrictions and provides consistent page loading.

The frontend loads Ethers.js 6.13.4 from jsDelivr. An internet connection is therefore required when loading the page unless the library is downloaded and served locally.

## 12. First-Time Application Setup

### Shipper profile
1. Open `http://127.0.0.1:5500` in browser profile A.
2. Ensure MetaMask is using the Ganache network and the intended Shipper address.
3. Select **Get Started** or connect the wallet.
4. Approve the MetaMask connection request.
5. Register the wallet as **Shipper**.
6. Confirm the registration transaction in MetaMask.

### Carrier profile
1. Open the same URL in browser profile B.
2. Ensure MetaMask is using the same Ganache network but a different Ganache address.
3. Connect the wallet.
4. Register the wallet as **Carrier**.
5. Confirm the registration transaction in MetaMask.

Both profiles must use the same local website URL, Ganache workspace, Chain ID, and deployed CarGrow contract address.


## 13. Important Operating Rules
- One wallet address can register only once per contract deployment.
- One wallet cannot act as both Shipper and Carrier.
- The Shipper creates and funds agreements.
- The Carrier accepts agreements and submits milestone evidence.
- The Shipper confirms evidence before payment is released.
- Milestone payouts are fixed at 30%, 30%, and 40%.
- Funding must occur within 48 hours after Carrier acceptance and before the delivery deadline.
- A Carrier may cancel an accepted agreement only before it is funded.
- No milestone evidence or confirmation is permitted after the deadline.
- Deadline expiry makes an incomplete funded agreement eligible for settlement; a blockchain transaction is still required to process the refund.
- Only unreleased escrow is refunded. Previously confirmed milestone payouts remain with the Carrier.
- Completed agreements award 10 non-transferable reputation points to the Carrier.

## 14. Restarting the Project Later
If the contract has already been deployed to the current Ganache workspace:

1. Start the same Ganache workspace.
2. Confirm MetaMask is connected to its network.
3. Open a terminal in the project folder.
4. Run:
   //powershell
   npm run serve
   
5. Open `http://127.0.0.1:5500`.

There is no need to compile and redeploy every time unless the Solidity contract changed, the Ganache blockchain was reset or a different Ganache workspace is being used.
